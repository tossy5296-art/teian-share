プライバシーポリシー

このページは、Claude MCP（以下「本ツール」）が Google のサービスから受け取るデータの扱いを説明するものです。

1. 受け取るデータ

本ツールは、Google アカウントの持ち主が許可画面で許可した範囲のデータだけを受け取ります。主なものは次のとおりです。

  • YouTube チャンネルの情報と、再生回数・視聴時間・流入元などのアナリティクス（読み取りのみ）

2. 使い道

受け取ったデータは、運営者自身の作業（チャンネルの週次レポートの作成など）のためだけに使います。広告や、ほかの目的には使いません。

3. 第三者への提供

受け取ったデータを第三者に販売・貸与・提供することはありません。ただし、運営者がレポートを共有する相手（チャンネルの関係者）に、集計した数字を渡すことがあります。

4. 保存と削除

  • 許可の情報（アクセス トークン）と取得したデータは、運営者のパソコンの中にだけ保存します。
  • 許可はいつでも取り消せます。Google アカウントの「サードパーティのアクセス」から本ツールを削除してください。取り消したあとは、新しいデータを受け取りません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. お問い合わせ

Google の許可画面に表示されるサポート用メールアドレスへご連絡ください。
